# Índice das 12 unidades analisadas no piloto R1

## O que significa “unidade”

Uma unidade é o objeto audiovisual delimitado que recebe uma análise completa. No piloto R1:

- para Instagram, uma unidade corresponde a um Reel completo;
- para cinema, uma unidade corresponde a uma sequência delimitada dentro do filme;
- cada unidade possui `analysis.md`, com a interpretação audiovisual;
- cada unidade possui `shots.json`, com o mapa temporal legível pelo sistema.

`shots.json` não afirma que todo intervalo é um corte físico. Ele distingue candidatos de mudança visual, intervalos alinhados à fala e boundaries ainda pendentes de revisão humana.

## O que você precisa revisar

Para cada uma das doze unidades, confira:

1. se a interpretação corresponde ao vídeo;
2. se os beats e timestamps fazem sentido;
3. se as técnicas realmente funcionam como descrito;
4. se alguma observação importante ficou faltando;
5. se o princípio transferível deve entrar no sistema;
6. se a unidade deve ser `approved`, `changes_requested` ou `rejected`.
