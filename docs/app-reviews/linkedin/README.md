# LinkedIn

- **Função demonstrada:** conectar perfil; organização e publicação corporativa somente após produto e scopes aprovados.
- **Scopes básicos:** `openid`, `profile`, `email`, `w_member_social`. Scopes de organização só entram no pedido quando a interface correspondente puder ser demonstrada.
- **Callback:** `${PUBLIC_APP_URL}/api/integrations/oauth/callback`.
- **Reviewer:** autenticar usuário de teste, confirmar recurso descoberto, demonstrar a ação aprovada e desconectar.
- **Pendente externo:** Página elegível, app vinculado, verificação da organização, produtos Community Management e tiers de acesso.
