# Pinterest

- **Função demonstrada:** conectar conta Business, listar boards e criar Pin de imagem por URL quando aprovado.
- **Scopes:** `user_accounts:read`, `boards:read`, `pins:read`, `pins:write`.
- **Callback:** `${PUBLIC_APP_URL}/api/integrations/oauth/callback`.
- **Reviewer:** conectar conta Business de teste, selecionar board, criar Pin claramente identificado como teste quando permitido e desconectar.
- **Pendente externo:** conta Business, app, Trial access e revisão para Standard access.
