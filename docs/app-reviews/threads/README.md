# Threads

- **Função demonstrada:** conectar o perfil, publicar conteúdo suportado, consultar insights e gerenciar respostas somente quando aprovados.
- **Scopes:** `threads_basic`, `threads_content_publish`, `threads_manage_insights`, `threads_read_replies`, `threads_manage_replies`.
- **Callback:** `${PUBLIC_APP_URL}/api/integrations/oauth/callback`.
- **Reviewer:** conectar uma conta de teste Threads, confirmar perfil, publicar conteúdo de teste não público quando possível, consultar resultado e desconectar.
- **Pendente externo:** app Threads dedicado, usuários de teste, URLs legais e revisão dos scopes.
